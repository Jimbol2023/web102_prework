Sea Monster Crowdfunding

Submitted by: Olabode Jimoh

Sea Monster Crowdfunding is a web project that displays information about the games funded by Sea Monster Crowdfunding, including funding status, contribution stats, and filtering controls.

## Required Features

The following **required** functionality is completed:

* [x] The introduction section explains the background of the company and how many games remain unfunded.
* [x] The Stats section includes information about the total contributions and dollars raised as well as the top two most funded games.
* [x] The Our Games section initially displays all games funded by Sea Monster Crowdfunding.
* [x] The Our Games section has three buttons that allow the user to display only unfunded games, only funded games, or all games.

The following **optional** features are implemented:

* No optional features were added.

## Notes

One challenge was organizing the game data so the page could update cleanly when users switch between all, funded, and unfunded games. Another was making sure the stats stayed easy to scan while still giving useful context about the crowdfunding progress.
